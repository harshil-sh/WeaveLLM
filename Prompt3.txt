Create a complete GitHub Actions CI/CD pipeline for the WeaveLLM repository.

## Files to create:

### 1. .github/workflows/ci.yml
Trigger on:
- push to main and develop branches
- pull_request targeting main
- workflow_dispatch (manual trigger)

Jobs:

#### Job 1: build-and-test
- runs-on: ubuntu-latest
- steps:
  - Checkout repo (actions/checkout@v4)
  - Setup .NET 8 (actions/setup-dotnet@v4 with dotnet-version: 8.0.x)
  - Cache NuGet packages:
    key: nuget-${{ hashFiles('**/*.csproj', 'Directory.Packages.props') }}
    path: ~/.nuget/packages
  - Restore: dotnet restore WeaveLLM.sln
  - Build: dotnet build WeaveLLM.sln --no-restore --configuration Release
  - Test: dotnet test WeaveLLM.sln --no-build --configuration Release
    --logger "trx;LogFileName=test-results.trx"
    --collect "XPlat Code Coverage"
  - Upload test results as artifact (actions/upload-artifact@v4)
  - Upload coverage to Codecov (codecov/codecov-action@v4)
    with token: ${{ secrets.CODECOV_TOKEN }} — mark as continue-on-error: true

#### Job 2: pack (depends on build-and-test)
- runs-on: ubuntu-latest
- Only runs on push to main or workflow_dispatch
- steps:
  - Checkout + Setup .NET 8 (same as above)
  - Restore + Build Release (same as above)
  - Pack each project individually with versioning:
    dotnet pack src/WeaveLLM.Core/WeaveLLM.Core.csproj
      --no-build --configuration Release
      --output ./artifacts
      -p:PackageVersion=${{ github.ref_name }}
    Repeat for: WeaveLLM.Providers, WeaveLLM.Memory,
    WeaveLLM.Observability, WeaveLLM.Extensions.DependencyInjection
    Use continue-on-error: false
  - Upload artifacts folder as artifact named "nuget-packages"

### 2. .github/workflows/release.yml
Trigger on:
- push of tags matching v* (e.g. v0.1.0-alpha, v1.0.0)

Jobs:

#### Job 1: publish-nuget
- runs-on: ubuntu-latest
- steps:
  - Checkout + Setup .NET 8
  - Restore + Build Release
  - Extract version from tag (strip leading 'v'):
    VERSION="${{ github.ref_name }}"
    VERSION="${VERSION#v}"
    echo "PACKAGE_VERSION=$VERSION" >> $GITHUB_ENV
  - Pack all 5 projects with -p:PackageVersion=${{ env.PACKAGE_VERSION }}
    output to ./artifacts
  - Push all .nupkg files to NuGet.org:
    dotnet nuget push ./artifacts/*.nupkg
      --api-key ${{ secrets.NUGET_API_KEY }}
      --source https://api.nuget.org/v3/index.json
      --skip-duplicate
  - Create GitHub Release (softprops/action-gh-release@v2):
    name: "WeaveLLM ${{ github.ref_name }}"
    body: "See CHANGELOG.md for details."
    files: ./artifacts/*.nupkg
    draft: false
    prerelease: ${{ contains(github.ref_name, 'alpha') || contains(github.ref_name, 'beta') }}
