You are building WeaveLLM — a strongly typed AI orchestration framework for .NET 8+, 
positioned as a production-grade LangChain alternative for .NET developers.

Create the full WeaveLLM.Core project with all core abstractions. The project lives at 
src/WeaveLLM.Core/WeaveLLM.Core.csproj

## Design principles to follow throughout:
- Errors as values: never throw for expected failures — use ChainResult<T>
- CancellationToken on every async method, always last parameter
- IAsyncEnumerable<T> for all streaming APIs
- Full XML doc comments on every public type and member
- Sealed classes where inheritance isn't intended
- Nullable reference types enabled (#nullable enable)
