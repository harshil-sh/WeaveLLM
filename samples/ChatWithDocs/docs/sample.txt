WeaveLLM is a .NET 8 AI orchestration framework that provides a unified interface for working with large language models from multiple providers — OpenAI, Anthropic, Azure OpenAI, and Ollama — through a single, provider-agnostic API. All operations return ChainResult<T> so errors are values, never exceptions, and every call supports CancellationToken for cooperative cancellation.

WeaveLLM ships a composable chain pipeline where every unit of work implements IChain<TInput, TOutput>. Chains can be connected with .Then() to form typed pipelines, and wrapped with middleware such as RetryMiddleware for exponential-backoff retries, CacheMiddleware for in-memory response caching, and RateLimitingMiddleware for token-bucket rate control. The optional WeaveLLM.Observability package adds OpenTelemetry tracing and metrics with zero configuration changes.

The RAG (Retrieval-Augmented Generation) subsystem in WeaveLLM.Memory lets you index any set of documents into a vector store and query them with natural language. DefaultRagPipeline handles the full loop: split text into overlapping chunks using RecursiveTextSplitter or FixedSizeTextSplitter, embed each chunk with an IEmbeddingModel, store vectors in IVectorStore (in-memory, Redis, Postgres/pgvector, or Qdrant), then retrieve the top-K nearest chunks at query time, render a prompt via IPromptTemplate, and generate a grounded answer with IChatModel. Sources are tracked per answer so responses are fully attributable.
